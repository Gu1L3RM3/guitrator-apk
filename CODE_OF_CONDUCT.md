# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discrimination are not tolerated and may lead to removal from the project.

Report problems privately through a [GitHub security advisory](https://github.com/Gu1L3RM3/guitrator-apk/security/advisories/new) or by contacting the maintainer on GitHub (@Gu1L3RM3).
